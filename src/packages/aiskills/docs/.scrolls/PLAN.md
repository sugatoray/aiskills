Two options; the env-var opt-in originally proposed here (`AISKILLS_AUTO_INSTALL=1`) is **dropped**: it costs the one-step install but keeps the install script, so scanners and pnpm's "ignored build scripts" warning still flag the package, and npm 7+ hides the "run `aiskills install`" hint unless `--foreground-scripts` is passed.
  - **A. Keep the current behaviour** (recommended if the one-command install matters most): `npm i -g` saves the skills and runs `npx skills add`; it never fails the npm install, and the README covers pnpm/bun/`--ignore-scripts`.
  - **B. Remove the `postinstall` script entirely** (recommended if avoiding install-time side effects matters most): no network calls, no writes to agent folders or `~` during `npm install`, nothing for scanners or pnpm to flag, the same behaviour under npm/pnpm/bun. The documented install becomes `npx @sugatoray-ai/aiskills install`, or `npm i -g @sugatoray-ai/aiskills && aiskills install` for a permanent command. Needs README, test and `AISKILLS_SKIP_*`/`CI` changes.
  - Do B before the first publish if at all: nothing is published yet, so no users would be broken.
