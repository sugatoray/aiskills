# Diagrams

Skills for explaining system architecture through working interactive diagrams.

| Skill | Description |
| --- | --- |
| [network-flow](network-flow/README.md) | Offline HTML diagrams with moving packets, orthogonal connections, scenario playback, and selectable components. |

Install with `npx skills add sugatoray/aiskills --skill network-flow` after merge,
or append `#<branch>` to the repository to install from a feature branch.

For Claude Code, register `/plugin marketplace add sugatoray/aiskills`, then
`/plugin install diagrams-skills@sugatoray`. Choose one installation route.
