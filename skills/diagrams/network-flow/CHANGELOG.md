# Changelog

All notable changes to this skill are documented here.

## [1.0.0] - 2026-10-17

### Added

- `/network-flow` instructions and repository-standard frontmatter metadata.
- Graph-driven offline HTML renderer with orthogonal obstacle-aware routing,
  animated packets, scenario playback, node tracing, pause/resume, and replay.
- Responsive layouts and keyboard/reduced-motion support.
- Standard-library graph validation and rendering CLIs.
- RAG example covering ingestion, retrieval, reranking, generation, citations,
  one query rewrite, recovery, and an explicitly alternative abstention path.
- Preserved original RAG HTML and its exact invocation together as
  `assets/examples/rag_demo.html` and `assets/examples/rag_prompt.md`.
- Schema, layout, telemetry boundary, and verification references.
- Unit and browser regression checks, agent interface metadata, maintainer notes,
  README, and diagrams-family plugin registration.
