# notaskill

This folder, and everything under it, is for maintaining the skills and
this repository. It is not a skill and holds no skills.

No skill will be created under `skills/notaskill/`. Put new skills in
their own group folder under `skills/` instead.

## Contents

- `meta/assets/icons-designer-*.html`: design mockups of the plugin icon
  styles that were explored. The chosen style is
  `icons-designer-ink-and-signal.html`, whose icons ship as each plugin's
  `icon.svg` and `icon.png`.
