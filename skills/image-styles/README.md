# Image styles

| Skill | Description |
| --- | --- |
| [artwallbg](artwallbg/README.md) | Generate a vivid scene in front of a monumental spray-painted wall. |
| [commentdrop](commentdrop/README.md) | Add simulated floating social comments to a still image. |

Install individually with `npx skills add sugatoray/aiskills --skill artwallbg` or `--skill commentdrop`. Append `#<branch>` to install before merge. Alternatively install the family with `/plugin marketplace add sugatoray/aiskills` followed by `/plugin install image-styles-skills@sugatoray`. Choose one installation route.
