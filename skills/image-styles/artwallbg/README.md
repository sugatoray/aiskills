# artwallbg

Create a scene before a huge spray-painted wall.

```text
/artwallbg [[ a girl ]]
```

Omit the context to use a girl as the subject. Supply style and aspect ratio preferences in the prompt.

An image generation or editing tool is required. Install with `npx skills add sugatoray/aiskills --skill artwallbg` after merge, or append `#<branch>` to the repository to install from a branch. See [SKILL.md](SKILL.md) for the behavior contract, [CHANGELOG.md](CHANGELOG.md) for release history, and [meta/MAINTAINERS.md](meta/MAINTAINERS.md) for maintenance.
