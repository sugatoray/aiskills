# Travel

Skills for trips and travel days: tracking flights and what's coming next.

| Skill | Description |
| --- | --- |
| [flight-status](flight-status/README.md) | Reports a flight's live status once or on a repeat: journey percentage by distance, miles covered and to go, a live route map, and a timestamped announcement on one composite report card. |

Install with `npx skills add sugatoray/aiskills --skill flight-status`, or in Claude Code
run `/plugin marketplace add sugatoray/aiskills` then
`/plugin install travel-skills@sugatoray`. Choose one installation route.
