# Changelog

All notable changes to the `scroll-explode` skill are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-09-15

### Added

- Initial release of `/scroll-explode` as the exploded-view and assembly/disassembly specialization of `/scroll-sequence`.
- Reversible assembled-to-exploded scroll semantics with assembly-aware narrative direction.
- Scene-planning guidance for subassemblies, separation axes, depth ordering, labels, spacing, and mechanically legible trajectories.
- Support for pre-rendered frame sequences, SVG/DOM layered parts, and optional WebGL/3D scenes.
- Separate product-storytelling and instructional visualization guidance, including responsive labels and reduced-motion behavior.
- Repository-standard skill frontmatter with MIT license, compatibility declaration, author/source metadata, and version `1.0.0`.
