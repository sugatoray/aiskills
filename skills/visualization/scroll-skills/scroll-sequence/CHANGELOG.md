# Changelog

All notable changes to the `scroll-sequence` skill are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-09-15

### Added

- Initial release of `/scroll-sequence` as the general-purpose scroll-linked visualization primitive.
- Support for concept, video, image-sequence, and DOM/SVG input modes.
- Deterministic normalized scroll-progress mapping with reversible playback.
- Guidance for pinned/sticky presentation, responsive rendering, reduced-motion fallbacks, and sequence verification.
- Composition guidance for delegating exploded-view semantics to `/scroll-explode` and supplied-media scrubbing to `/scroll-scrub`.
- Repository-standard skill frontmatter with MIT license, compatibility declaration, author/source metadata, and version `1.0.0`.
