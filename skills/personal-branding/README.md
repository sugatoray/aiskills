# Personal-branding skills

Skills for building a person's own public-facing presence from
researched, sourced data — currently: researching a named individual
from public sources and building them a tasteful, professional personal
landing page.

Organized as a flat family (one skill today) under this folder, the
same pattern `skills/stata/` uses for `stata-recipes`:

| Skill | Purpose |
| --- | --- |
| [`landing-page-builder/`](landing-page-builder/) | Researches a named person, structures the findings into a sourced YAML data file, and renders a self-contained, tasteful HTML/CSS personal landing page from it. |

More skills will be added here over time (e.g. a resume/CV builder, a
speaker-bio generator) as they're written, following the same
YAML-data-first, no-generic-slop approach.

See [`landing-page-builder/README.md`](landing-page-builder/README.md)
for that skill's own details, and
[`meta/MAINTAINERS.md`](meta/MAINTAINERS.md) for the family-level
Claude Code plugin manifest and versioning notes.
