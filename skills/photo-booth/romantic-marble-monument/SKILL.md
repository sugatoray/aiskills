# Romantic Marble Monument

Create the image itself; do not merely describe it.

## Workflow

1. Inspect the user's source photograph before editing or generating.
2. Read `assets/PROMPT.md` completely and use it as the governing generation brief.
3. Use `assets/sample.png` as the composition, mood, material, lighting, and museum-presentation template.
4. Treat the user's supplied photograph as the primary identity reference unless they request anonymous or generated faces.
5. Preserve both subjects' recognizable facial geometry when requested, but render every visible human feature as the same white Carrara marble material.
6. When privacy is requested, replace both identities with clearly fictional adult faces while preserving pose, relationship, emotional tone, and all non-identifying composition cues. Never claim that generated faces depict real people.
7. Generate or edit with the image-generation tool and return the resulting image.
8. Inspect the result against the acceptance checks. If a critical check fails, revise it before presenting it.

## Acceptance checks

- Show exactly one adult woman and one adult man.
- Render both figures unmistakably in identical ivory-white Carrara marble; retain no natural skin, eye, or hair color.
- Make the figures read as one coherent sculpture, not humans composited into stone.
- Show the engagement ring as a restrained sculptural detail.
- Convey love, trust, compassion, companionship, joy, and a shared future.
- Use only humanistic and romantic books or symbols; exclude technical, scientific, professional, and career references.
- Engrave `A BRIGHTER TOMORROW TOGETHER` exactly on the pedestal.
- Keep all text legible, correctly spelled, and unmirrored.
- Match the template's museum hall, warm lighting, natural perspective, and medium depth of field.
- Avoid nudity, funerary gloom, wedding-prop kitsch, generic idealized faces, extra limbs, malformed hands, and duplicated accessories.

## Adaptation rules

- Preserve joyful expressions from joyful source photographs; do not force solemn expressions.
- Translate contemporary clothing into modest, flowing Greco-Roman drapery.
- Express ethnicity and individuality through sculptural form, never unequal marble pigmentation.
- Keep symbolic objects restrained so the couple remains the visual center.
- Follow a user-requested inscription exactly; otherwise retain the default inscription.
