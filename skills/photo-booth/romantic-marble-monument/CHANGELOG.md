# Changelog

All notable changes to the `romantic-marble-monument` skill are
documented here. Format based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.1] - 2026-09-15

### Changed

- Renamed the skill from `create-romantic-marble-monument` to
  `romantic-marble-monument` and updated invocation, installation, interface,
  and maintenance documentation accordingly.

## [0.1.0] - 2026-09-15

### Added

- Initial `SKILL.md` workflow for converting an adult couple's photograph into
  a romantic, museum-quality Carrara-marble engagement monument.
- `assets/PROMPT.md` with likeness-preserving and privacy-preserving modes,
  marble-material constraints, humanistic symbolism, museum direction, and
  exact inscription requirements.
- `assets/sample.png` as the reusable composition and visual template.
- `agents/openai.yaml` and `assets/icon.svg` for the Skills interface.
- `meta/MAINTAINERS.md` with layout, maintenance invariants, validation, and
  versioning guidance.
- Human-facing installation, invocation, privacy, and file documentation in
  `README.md`.
