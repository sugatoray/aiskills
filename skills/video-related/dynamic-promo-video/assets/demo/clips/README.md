# Demo narration clips

The approved narration for the `--demo` variants, in ElevenLabs voice
`TABZn6CDfjMNGrsnGzzD` (model `eleven_multilingual_v2`). Each file is one
line of narration; both variants share them. `<variant>/clips.json` maps each
scene (`vo<scene>`) to a file here. `install-skill.mp3` has "Shoo-gaw-doe Ray"
and "A.I. skills" spliced in, as approved by the repo owner.

| File | Line |
| --- | --- |
| `launch-video.mp3` | Meet your next launch video, built entirely from code. |
| `problem.mp3` | Promo videos take hours of editing, and they go stale with every release. |
| `scene-engine.mp3` | Here, every scene is HTML, animated frame by frame, with camera moves over real screenshots. |
| `install-commands.mp3` | Install commands type themselves out, exactly as your users will run them. |
| `story.mp3` | Write the story, add a voice, and the scenes stretch to fit the narration. |
| `render-share.mp3` | Render, mix, verify, and share. Made with the dynamic promo video skill. |
| `placeholder-bridge.mp3` | That was a placeholder for your own video. Here is how to make one. |
| `install-skill.mp3` | Install it from Shoo-gaw-doe Ray slash A.I. skills: with npx skills, the Claude Code plugin, or the A.I. skills npm package. |
