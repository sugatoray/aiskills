# Video Related

Skills that produce videos with the agent: scenes built from code, real
screenshots, narration and music.

| Skill | Description |
| --- | --- |
| [dynamic-promo-video](dynamic-promo-video/README.md) | Builds a short (~25-45s, 1280x720) narrated promo or intro video for a library, app or product: animated HTML scenes rendered frame by frame with Playwright, encoded with ffmpeg, a TTS voiceover, and ducked background music. |

Install with `npx skills add sugatoray/aiskills --skill dynamic-promo-video`, or in
Claude Code run `/plugin marketplace add sugatoray/aiskills` then
`/plugin install video-related-skills@sugatoray`. Choose one installation route.
