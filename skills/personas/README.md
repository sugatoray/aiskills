# Personas

Skills that have the agent adopt an expert persona to share how the best
practitioners in a role think, work, and grow.

| Skill | Description |
| --- | --- |
| [prodigy](prodigy/README.md) | Acts as the top performer in a role or field and returns a playbook: problem framing, delivery, pitfalls, operating principles, and a learning plan. |

Install with `npx skills add sugatoray/aiskills --skill prodigy`, or in Claude Code
run `/plugin marketplace add sugatoray/aiskills` then
`/plugin install personas-skills@sugatoray`. Choose one installation route.
