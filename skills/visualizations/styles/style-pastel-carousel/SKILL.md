# Pastel Carousel Style Skill

## Purpose
Provide structured guidance for generating educational carousel-style content
in a modern pastel flat-illustration aesthetic commonly used on Instagram and LinkedIn.

## Capabilities
- Produce slide-by-slide carousel outlines.
- Apply pastel color palettes and soft UI elements.
- Use flat illustration descriptions (not actual images).
- Maintain high whitespace, clean typography, and friendly educational tone.
- Include optional automation/workflow iconography (arrows, sticky notes, stars).

## Style Rules

### Color Palette
Use soft, muted tones:
- Backgrounds: #F7EFEA, #FDF7F3, #FFF9F5
- Accents: #F4C2C2 (pink), #F7D96F (yellow), #A7D3F0 (blue)
- Text: #2E2E2E (primary), #6A6A6A (secondary)

### Typography (descriptive only)
- Headings: Bold, rounded sans-serif, large.
- Body: Clean, friendly sans-serif.
- Emphasis: Soft highlight blocks or colored tags.

### Layout
- Generous whitespace.
- Centered or left-aligned text blocks.
- Decorative doodles: stars, arrows, sticky notes, sparkles.
- Flat vector human/workspace scenes described textually.

### Illustration Guidelines
Describe illustrations using:
- Simple shapes
- Minimal shading
- Rounded corners
- Cozy productivity props (laptop, notebook, flowers, drink)

### Voice & Tone
- Friendly, educational, concise.
- Action-oriented ("Save time", "Automate repetitive work").
- Avoid jargon unless requested.

## Output Formats

### 1. Carousel Outline
When asked for a carousel:
- Provide numbered slides.
- Each slide includes:
  - Title
  - 2–4 bullet points
  - Illustration description
  - Optional icon flow (e.g., AI → Step → Output)

### 2. Single-Slide Content
When asked for a single slide:
- Provide heading, subheading, bullets, and illustration description.

### 3. Visual Direction
When asked for visual style:
- Provide palette, layout, illustration notes, and typography guidance.

## Invocation
This skill activates when the user requests:
- Carousel design
- Slide content
- Pastel flat illustration style
- Productivity-style educational visuals
- "Instagram carousel", "LinkedIn carousel", "pastel aesthetic", or similar

## Examples

### Example: Carousel Slide
**Slide 1 — What You Can Automate**
- Repetitive text formatting
- Summaries and reports
- Inbox triage
Illustration: Person at a laptop with pastel flowers and sticky notes floating around.

### Example: Visual Direction
Use a soft cream background (#FFF9F5), rounded shapes, and doodle arrows pointing
toward key text blocks. Add a flat illustration of a workspace with warm lighting.
