# Development skills

Skills for software-development workflows that aren't specific to any
one language or project — working with GitHub issues and pull requests,
and (over time) other repo/process tasks that cut across projects.

Organized into subgroups by area, each holding one or more skills:

| Subgroup | Purpose |
| --- | --- |
| [`issues-pull-requests/`](issues-pull-requests/) | GitHub issues and pull requests — filing issues for a PR's work and keeping the PR's title/description in sync with them. |

More subgroups will be added here over time (e.g. code review, release
management) as skills for them are written — each gets its own
subfolder with its own `README.md`, following the same pattern as
`issues-pull-requests/`.
