# Productivity

Skills that help run day-to-day work: meetings, planning and follow-through.

| Skill | Description |
| --- | --- |
| [meeting-agenda](meeting-agenda/README.md) | Turns an agenda into an offline HTML slide deck with a ring countdown per item, a per-item meeting progress bar, and an in-page editor. |

Install with `npx skills add sugatoray/aiskills --skill meeting-agenda`, or in Claude Code
run `/plugin marketplace add sugatoray/aiskills` then
`/plugin install productivity-skills@sugatoray`. Choose one installation route.
